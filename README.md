## 需要准备

- Windows 10 / 11，64 位
- 能上网
- 一个 DeepSeek 账号（装好后可以直接登录），或者 DeepSeek 开放平台的 API Key（[platform.deepseek.com](https://platform.deepseek.com)，不是聊天 App）。聊天费用由 DeepSeek 按用量收，从你自己的账号扣。

## 怎么装

1. 下载 zip，解压到任意文件夹（别在压缩包里直接双击）。
2. 双击「① 双击安装」，等它做完安装前检查和安装。
3. 用 DeepSeek 账号登录，或者粘贴你的 API Key。
4. 输入激活码。激活码免费，关注 B 站「玩AI的Sandy君」领取。

以后有新版本，软件里会提示在线更新，不用重新下载。

## 和普通网页 AI 不一样的地方

- **长期记忆**：普通网页 AI 每开一个新对话，都是第一次见你。这里它会记住你的专业、习惯、在做的事，不用每次重新交代。记忆存在你自己电脑上，不上传给我们。
- **项目树**：大一点的活，聊着聊着容易跑偏，AI 还会说已经做完了。项目树把每一步做了什么、定了什么、踩过什么坑、下一步干什么都存下来，下个项目接着用。
- **桌宠、壁纸、手机上聊**：女仆鲸鱼娘桌宠（全屏自动躲开），图片和视频壁纸，可以接飞书 / QQ 在手机上和它说话。

### 日常的活

写 Word / PPT / Excel，看图（课表、题目、截图），自己开浏览器上网查资料，每次对话花了多少钱都写明白。

## 隐私

- 记忆和聊天记录只存在你的电脑上。
- 消息通过你自己的账号或 Key 发给 DeepSeek。
- 激活只发送激活码和一个匿名机器编号。
- 卸载时会在桌面留一份记忆备份，重装后可以放回去。
